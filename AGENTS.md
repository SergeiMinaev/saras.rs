# Руководство по репозиторию

## Структура проекта и организация модулей
- `src/` содержит Rust-крейт: `lib.rs` для общих модулей и `main.rs` как точку входа бинарника `saras`.
- Ключевые домены вынесены в подмодули, например `auth/`, `db.rs`, `http.rs`, `storage/`, `users/`, `posts/`, `notifications/`.
- Шаблоны и локализация находятся в `src/tpl.rs` и `src/l10n.rs`; изображения и утилиты — в `src/images/` и `src/util.rs`.
- Примеры конфигураций: `example.saras.toml` и `saras.toml`; настройки БД — в `lpsql.toml`.

## Сборка, тесты и запуск
- `cargo build` — собрать проект.
- `cargo run --bin saras` — запустить приложение по умолчанию (выводит “Running default app.”).
- `cargo run --bin saras -- hash-pwd <pwd>` — сгенерировать хэш пароля через CLI-команду.
- `cargo test` — запустить тесты (их пока нет, но это стандартная точка входа).

## Стиль кода и соглашения об именовании
- Следуйте Rust 2021: отступы 4 пробела, `snake_case` для модулей/функций, `CamelCase` для типов, `SCREAMING_SNAKE_CASE` для констант.
- Специфичных настроек форматирования нет; при заметных изменениях используйте `cargo fmt` и `cargo clippy`.

## Рекомендации по тестированию
- Выделенного набора тестов не обнаружено ни в `tests/`, ни через `#[cfg(test)]` модули.
- При добавлении тестов: интеграционные — в `tests/`, модульные — `mod tests` рядом с кодом.

## Коммиты и pull request
- Недавние сообщения коммитов короткие и по делу; встречается формат `Topic: detail`, язык — русский или английский.
- Держите коммиты небольшими и с понятным описанием изменений поведения.
- В PR указывайте: краткое описание, изменения конфигов (если есть), релевантные логи или скриншоты.

## Конфигурация и запуск
- Точка входа по умолчанию вызывает `default_app::run()`; для локального запуска настройте `saras.toml` и `lpsql.toml`.
- Путь сокета указан в `saras.sock`; при изменении обновите конфиги.
